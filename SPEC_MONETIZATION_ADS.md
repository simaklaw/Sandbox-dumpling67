# SPEC_MONETIZATION_ADS.md — задание для Claude Code: реклама + «убрать рекламу за 600₽»

## 0. Контекст и модель

Приложение «Детская площадка» (59 мини-игр, офлайн-first). Новая модель монетизации:

- **Все игры бесплатны** — дети имеют доступ ко всему.
- **Реклама** (Яндекс.Реклама / ВК Реклама) показывается **редко и мягко**: при входе в приложение и при выходе из игры, с лимитами и защитой от случайных кликов.
- **«Убрать рекламу навсегда» за 600₽** — через ЮKassa (владелец — самозанятый), на уже настроенном лицензионном контуре (см. `SPEC_MONETIZATION_YOOKASSA.md`).
- Напоминание о покупке — только в родительских настройках, ребёнок его не видит.

Реклама и покупка — **только для родителя / на безопасных точках**, не внутри игрового процесса. Никаких CTA ребёнку.

Связь с другими спеками:
- `SPEC_PHASE1_BILLING.md` (Room миграция 5→6, `entitlements`, `EntitlementManager`) — используется как есть.
- `SPEC_MONETIZATION_YOOKASSA.md` (backend ЮKassa, лицензионные ключи, подпись Ed25519) — используется как есть. Настоящая спецификация — это **надстройка** над ней.

Загруженные справочные материалы (книги по мобильной разработке, HTML/CSS, веб-формам) используются для общих инженерных решений в `backend/` и UI-компонентах; по специфическим вопросам детских приложений и рекламных сетей опираемся на актуальные правила платформ.

## 1. Неизменяемые принципы

1. Детский контур (игры, каталог, главный экран) **офлайн и без сетевых вызовов**.
2. Реклама и покупки — **только в родительской зоне** и на безопасных точках (вход в приложение, выход из игры). Никаких CTA, цен и замков в игровом процессе.
3. Триггер **«при успехе/награде» запрещён** — заменяется на «при выходе из игры». Реклама в момент позитивной эмоции ребёнка — максимальный риск и по ФЗ, и по фрод-кликам.
4. Реклама показывается **редко**, с жёсткими лимитами (раздел 3.2).
5. Защита от случайных кликов обязательна (раздел 3.3).
6. Если куплен `remove_ads` — реклама отключена полностью, навсегда.
7. Ребёнок никогда не видит: цен, кнопок покупки, напоминаний о покупке, замков.
8. Премиум-гейтинг игр (разделение на бесплатное/платное) **выключен**, но код сохраняется флагом — для будущих платных функций.
9. Боевые игры (Зелик, тир, лук и т.п.) **не трогать** — они остаются как есть.
10. Каждый шаг — отдельный PR, зелёный CI, обновление `DEVICE_CHECKLIST.md`. Device-проверки — владелец.

## 3. Фаза 2. Рекламный модуль `ads/` (агент)

### 3.1. Триггеры

| Триггер | Правило | Формат |
|---|---|---|
| **При входе в приложение** | НЕ на первом запуске; только со 2–3 запуска; не чаще 1 раза в день | Нативная карточка на главном экране с пометкой «Реклама» |
| **При выходе из комнаты игры** | Вероятность 30–50% **ИЛИ** каждый 2–3 выход; с глобальным кулдауном | Полноэкранная или оверлей с большой кнопкой закрытия ≥48dp |
| **При успехе / награде** | ❌ **запрещено** | — |

### 3.2. Жёсткие лимиты (константы в `ads/AdConfig.kt`)

```kotlin
object AdConfig {
    const val GLOBAL_COOLDOWN_MS = 5 * 60 * 1000L     // 5 минут между показами
    const val DAILY_LIMIT = 4                         // максимум 4 показа в день
    const val MIN_LAUNCH_BEFORE_FIRST_AD = 3          // первые N запусков — без рекламы
    const val CLICKABILITY_DELAY_MS = 1500L           // кликабельность через 1.5 сек
    const val EXIT_PROBABILITY = 0.4f                 // 40% шанс показа при выходе
    const val HOME_DAILY_LIMIT = 1                    // на главном — 1 раз в день
}
```

Все лимиты — в одном месте, легко меняются. Тесты на лимиты обязательны.

### 3.3. Защита от случайных кликов

- Кнопка закрытия видна **сразу**, размер ≥48dp.
- Кликабельность рекламы (тапы по самому креативу) появляется **с задержкой 1.5 сек** — это защищает и от случайных детских кликов, и от фрод-кликбейта рекламной сети.
- Креативы: только детские/нейтральные, без «кликни сейчас», без мигания.
- Явная пометка «Реклама» на каждой показанной единице.
- Никаких авто-редиректов и авто-открытия сторов/браузера.

### 3.4. Архитектура

```
ads/
  AdConfig.kt             // лимиты и константы
  AdManager.kt            // единая точка: canShow(trigger), show(activity, trigger), markShown()
  AdProvider.kt           // интерфейс (реальный SDK сейчас / NoopProvider для тестов)
  yandex/YandexAdProvider.kt     // flavor-специфичный адаптер
  vk/VkAdProvider.kt             // flavor-специфичный адаптер
  components/
    AdCard.kt             // нативная карточка для главного экрана
    AdInterstitial.kt     // полноэкранный блок с большой кнопкой закрытия
```

**Интеграция с `EntitlementManager`:** перед любым показом — проверка `unlockedProducts.contains("remove_ads")`. Если да — не показываем ничего.

**Ленивая инициализация:** SDK рекламы инициализируется только при первом вызове `AdManager.show()`, не в `Application.onCreate`.

**Триггеры в коде:**
- `MainActivity.onCreate` → `AdManager.tryShowOnLaunch()` (проверяет номер запуска через SharedPreferences `launch_count`).
- `MainActivity.leaveGame(pageIndex)` → `AdManager.tryShowOnExit()` (вероятность + кулдаун).

**Офлайн-поведение:** нет сети → не показываем, не ломаем игры.

### 3.5. Тесты (unit)

- Лимиты соблюдаются (5 минут, 4/день, 1 на главном/день).
- `remove_ads` блокирует показ.
- Первые N запусков — без рекламы.
- Идемпотентность: повторный триггер в кулдауне — без показа.
- Provider-заглушка (`NoopProvider`) корректно заменяется реальным SDK.

## 4. Фаза 3. Продукт «Убрать рекламу» (агент + владелец)

Используется **готовый лицензионный контур** из `SPEC_MONETIZATION_YOOKASSA.md` (backend ЮKassa, Room-таблица `entitlements`, Ed25519). Меняем только содержимое.

### 4.1. Конфиг продукта

В `backend/products.json`:
```json
{"id": "remove_ads", "price": 600, "kind": "durable", "title": "Без рекламы навсегда"}
```

Другие продукты (tips и т.п.) — на усмотрение владельца.

### 4.2. UI в родительских настройках

- Карточка **«Убрать рекламу навсегда — 600₽»** с ценой с сервера (`formattedPrice`).
- Поле активации ключа (если родитель уже купил и получил ключ).
- Напоминание «Смотрите рекламу? Уберите её навсегда» — **только в родительской зоне**, не в детском контуре.
- После покупки — подтверждение «Реклама отключена навсегда».

### 4.3. Связь с `AdManager`

При активации лицензии `remove_ads`:
1. Сохраняется в `entitlements` (`source="direct"`, `kind="durable"`, `active=true`).
2. `EntitlementManager.unlockedProducts` эмитит обновление.
3. `AdManager` подписан на поток и **полностью отключает показ** всех форматов рекламы.

### 4.4. Что делает владелец (параллельно)

- Подключить ЮKassa как самозанятый, получить `shopId`/`secretKey`.
- Домен + HTTPS + сервер для `backend/`.
- Выполнить `python backend/tools/gen_keys.py`, публичный ключ → `buildConfigField` в `app/build.gradle.kts`.
- Решить состав `winter_pack` (если добавляем).

**Критерий готовности:** можно купить «убрать рекламу» за 600₽ через ЮKassa, активировать ключ, реклама исчезает; CI зелёный.
