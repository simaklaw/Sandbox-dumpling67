# Правила проекта «Детская площадка»

Android-приложение (Kotlin, Compose, Room, JBox2D), офлайн, для малышей. Подробности и структура — в `README.md`, план — в `ROADMAP.md`.

## Как проверять
- Android SDK в окружении агента нет: компиляцию проверяет только CI (`.github/workflows/android.yml`, на каждый push). После правок кода пушить ветку и смотреть `gh run list` / логи.
- Локально: `gradle :app:testDebugUnitTest :app:assembleDebug` (Gradle 9.3.1, JDK 21).
- Версии зависимостей — только в `gradle/libs.versions.toml`, без хардкода в `app/build.gradle.kts`.

## Что нельзя ломать
- Схема Room заморожена до первого релиза (см. ROADMAP A6). Entity и DAO не менять и не «чистить» без миграции.
- Ресурсы подгружаются по имени (`getIdentifier`, суффикс `_en` у озвучки, `pet_%02d`). Файл в `res/raw` или `res/drawable*` нельзя удалять только потому, что `R.raw.x` нигде нет: сначала искать строки и шаблоны имён.
- R8/`shrinkResources` не включать без keep-правил (причина выше).
- Разрешения `INTERNET` нет и быть не должно: приложение детское, офлайн.
- `PelmenRunnerScreen` и его физика живые (игра №5), удалять нельзя.
- Новая игра: добавить ветку в `when(pageIndex)` в `MainActivity` и пункт в `FolderScreen`/`HomeScreen`; индексы не переиспользовать.

## Соглашения
- Отладочные элементы интерфейса показывать только под `BuildConfig.DEBUG` (малыши их видеть не должны).
- Состояние Flow в Compose читать через `collectAsStateWithLifecycle()`.
- Работа с `SharedPreferences`, звуком и вибрацией — best-effort: сбой не должен ронять игру. В остальном пустой `catch` не писать.
- Звуки — через `SoundManager`/`SoundCatalog`; новые файлы называть как в `sounds_checklist.csv`.
- WebView-игры (Хваталка): только локальные ассеты через `shouldInterceptRequest`, файловый и content-доступ выключены, на паузе приложения WebView ставить на паузу.

## Удаление мёртвого кода
Перед удалением объявления проверять достижимость от `MainActivity` (а не только «имя встречается один раз»), тесты считать отдельными потребителями. После пакета удалений — push и зелёный CI.
